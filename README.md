# 💫 About Me:
Hi, I’m Unique, popularly known as Mr. Unique.<br>I’m a passionate developer from Kerala, working across multiple technologies including C++, JavaScript, Python, PWN, and Lua. I specialize in building and managing game servers, bots, and backend systems, with strong hands-on experience in SA-MP / OpenMP development, Discord bots, and server automation.<br><br>I’m a core developer of Mallu Andreas Roleplay (MARP) and part of the founding crew of Cybroxa, where I actively contribute to development, infrastructure, and system management. From scripting complex gameplay systems to handling hosting panels, VPS setups, and performance optimization — I enjoy turning ideas into reliable, scalable solutions.<br><br>Always learning, always building.<br>If it’s about game servers, backend logic, hosting, or automation, you can ask Mr. Unique. 😊⚡
